# Короткое описание для сдачи

> Перед отправкой выполните чеклист `ACCEPTANCE.md` и убедитесь, что по ссылке размещён этот релиз.

**Проект:** «Мой день» — To-Do List.

**Ссылка:** https://todo-d0d24.web.app

**Исходники:** приложенный архив проекта. Если они загружены в GitHub, добавьте реальную ссылку на репозиторий.

Реализованы все четыре требования: добавление, отметка выполнения, удаление и сохранение задач после обновления страницы. Основной сценарий работает без регистрации. Дополнительно есть редактирование, отмена последнего удаления, фильтры, прогресс, адаптивный неоновый интерфейс и Google-вход с личным облачным списком.

Технологии: React, TypeScript, Vite, Firebase Authentication, Cloud Firestore и Firebase Hosting. Исходники содержат автоматические проверки и инструкции запуска.

Ограничение: полноценный офлайн-запуск не заявлен; для входа и облачной синхронизации нужен интернет. Результаты и границы проверок указаны в `docs/QA.md`.
