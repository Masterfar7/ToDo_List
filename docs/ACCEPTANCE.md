# Ручная приёмка перед отправкой

Не отмечай пункт выполненным только потому, что он работает локально. Этот список предназначен для **новой опубликованной версии**.

## Обязательные требования

- [ ] Открыть Hosting URL в новой сессии браузера без входа.
- [ ] Добавить задачу кнопкой и клавишей Enter.
- [ ] Обновить страницу: обе задачи сохранились.
- [ ] Выполнить задачу, обновить: отметка сохранилась.
- [ ] Удалить задачу, обновить: удаление сохранилось.
- [ ] Убедиться, что нет ошибок в консоли браузера.

## Дополнительная полировка

- [ ] Отредактировать задачу; Enter сохраняет, Escape отменяет.
- [ ] Восстановить удалённую выполненную задачу; галочка остаётся.
- [ ] Проверить пробелы, русский текст, эмодзи, длинные слова и текст до 300 символов.
- [ ] Пройти интерфейс клавиатурой: видимый фокус, подписи кнопок, доступ к задачам по skip-link.
- [ ] На реальном телефоне форма добавления видна на первом экране; нет горизонтальной прокрутки.
- [ ] Проверить целевую сеть, например домашний интернет и мобильную сеть.

## Google и облако

- [ ] Войти через Google на настоящем опубликованном домене.
- [ ] Явно скопировать локальные задачи, проверить текст и выполненные задачи.
- [ ] Повторить копирование: дубликаты не появились.
- [ ] Войти тем же аккаунтом на втором устройстве: задачи доступны.
- [ ] Изменить, выполнить, удалить и восстановить задачу; проверить обновления на втором устройстве.
- [ ] Выйти, войти другим Google-аккаунтом: чужие задачи не видны.
- [ ] Закрыть popup входа: локальный список не исчез.
- [ ] Отключить интернет: нет ложного сообщения об успешном облачном сохранении; выход из аккаунта остаётся возможен.

## Сдача

- [ ] На сайте именно финальная версия; обновлены Hosting и Firestore Rules.
- [ ] К ссылке приложены исходники или реальная ссылка на репозиторий.
- [ ] README и результаты тестов соответствуют файлам.
- [ ] Указано использование AI, без выдуманных ручных проверок.
- [ ] В репозитории нет сервисных аккаунтов, токенов CLI и паролей.
